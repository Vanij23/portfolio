AWS Event-Driven Data Processing Pipeline

Uploading a CSV to Amazon S3 triggers everything else. A Lambda function processes the file, DynamoDB stores the rows, API Gateway serves them, and a dashboard on EC2 shows the results live. It replaces manual data entry with one upload.

  • AWS Lambda

Post-Operative Medication Tracker

A bilingual (English and Marathi) progressive web app that tracks dosing schedules after surgery, including a tapering medication, so caregivers don't have to keep it in their heads.

  • Syncs across devices in real time with Vercel Functions and Upstash Redis, so several caregivers share one record.
  • Handles simultaneous edits with a last-write-wins rule.
  • Sends reminders by medicine and dose, and keeps a full dose history.
  • JavaScript
  • PWA
  • Vercel
  • Upstash Redis
  • Notifications API
