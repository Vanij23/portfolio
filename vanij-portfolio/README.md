Personal portfolio built for LCA 3 (Cloud Infrastructure Management).
Computer Science undergraduate at MIT World Peace University, Pune.

**Live site:** https://YOUR-LINK.vercel.app  <!-- replace after deploying -->

## What is on the site
- About, projects, experience, skills and education, with a downloadable resume
- **Pipeline demo:** drop in any CSV and watch it move through S3, Lambda, DynamoDB, API Gateway and an EC2 dashboard. It runs in the browser and mirrors my real AWS project
- **Terminal:** press the backtick key and try `help`
- Dark and light mode, a loading screen, and a globe that spins and follows the cursor
- Responsive on phone and desktop

## Built with
HTML, CSS and vanilla JavaScript. No frameworks. Font: Inter. Hosted on Vercel from this repository.

## Projects shown
1. AWS Event-Driven Data Processing Pipeline (S3, Lambda, DynamoDB, API Gateway, EC2, CloudWatch)
2. Post-Operative Medication Tracker (bilingual PWA, Vercel Functions, Upstash Redis)
3. Cloud-Hosted Retro Games Website (AWS EC2, S3, RDS, IAM)
